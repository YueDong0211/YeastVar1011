YeastVar1011 - Windows portable workstation

Extract the complete ZIP, then open YeastVar1011\START.cmd.
Use STOP.cmd to stop this folder's local server.
CREATE-SHORTCUT.cmd creates a shortcut for the extracted folder.
Python, Node.js and administrator rights are not required.
Do not run START from a ZIP preview or copy index.html alone.

Share the complete ZIP. It contains the application, catalogue, citations,
visual assets, export libraries and documentation. RELEASE.json identifies
the release; package-manifest.json verifies individual file hashes.

The optional Qwen language model is a separate first-use download of about
519 MB, or it can be imported through the assistant's model controls.
The research catalogue and normal plan exports work without loading it.

Plans and preferences are stored in the current browser and website address.
Export a plan JSON before moving computers, browsers or addresses; import
that JSON in the destination workstation. Sharing the ZIP does not include
your private browser plans, notes, model cache or settings.

The interface prepares research plans. Sequencing analysis runs separately
with the source release's Linux/SLURM workflow and your configured inputs.
See docs/RELEASES.md for current downloads, entry points and sharing guidance.
