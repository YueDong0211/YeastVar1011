YeastVar1011 便携版 · Windows 使用说明

怎样打开
1. 先把整个 ZIP 完整解压到一个普通文件夹。
2. 双击 START.cmd。程序检查文件完整性，等待本地服务就绪后，再打开浏览器。
3. 希望从桌面打开：双击 CREATE-SHORTCUT.cmd 生成快捷方式。
4. 使用完毕：双击 STOP.cmd，仅停止这个文件夹对应的本地服务。

不需要安装 Python、Node.js 或额外软件，也不需要管理员权限。
使用 Windows 自带的 PowerShell 和 .NET。后台服务仅监听本机 127.0.0.1。
支持中文和空格目录。启动不依赖当前文件夹；快捷方式的“起始位置”也不影响定位。
重复双击会复用已就绪的服务。通常重启后复用原端口，保留同一浏览器的本地方案。
端口被占用时自动选择其他空闲端口，不会关闭或修改其他程序。

怎样发给别人
发送完整 ZIP。请对方先完整解压，再双击 START.cmd。
不要只发送 index.html，也不要发送你自己的桌面快捷方式。
不要在压缩包预览窗口里直接运行 START。
如果移动了解压后的文件夹，重新运行 CREATE-SHORTCUT.cmd。

工作方案流程
默认使用经典工作台。选择“进入沉浸式设计”后，可继续经典模式或点击开始体验；只有明确开始才加载三维酵母场景。两种方式编辑同一份方案，切换时保留当前环节；返回经典模式会关闭三维渲染。
沉浸模式支持液态观察场景和六种镜头构图，可拖动观察、滚轮缩放、调节细胞壁显露程度，并生成真实方案预览。选择指标、工具、marker 和查看证据会触发不同的模型反馈；切换环节会收起当前面板并展开下一步。场景动态可暂停，“减少动态”会暂停背景和镜头转场。
经典工作台提供本步内容快捷定位、可随时使用的前后步导航、清除搜索与筛选，以及更多操作菜单。
侧栏按“制定方案 / 数据与证据 / 分析与拓展 / 个人工作区”分组。
QC 指标和完整流程均可按环节浏览，设置按显示、证据规则与来源分栏。
从首页进入六步工作台：研究范围 → 原始数据与 QC → 细胞状态与标记 → 表达噪音与验证 → 注释后分析与扩展 → 审阅与导出。
研究方向可以多选，点击“保存并返回”回到当前步骤。侧栏可以固定，或鼠标移入自动展开。

本地数据与记忆
在“设置”、经典模式“更多操作”、小助手设置或沉浸模式顶部，可打开本地数据管理。
“重置界面与模型”保留研究内容和当前语言；“清理临时视图”还会保留外观设置。
“删除本站全部本地数据”需要确认，包含方案、草稿、个人内容和小助手图片；请先下载需要的方案备份。方案备份不含独立笔记、反馈、小助手图片及连接设置。
这些操作只管理此浏览器中的本站数据，不清除浏览器自身的 HTTP 缓存。

怎样保存研究方案
网站的方案、勾选与备注保存在当前浏览器的本地存储中。
建议定期在“审阅与导出”中导出方案 JSON，换电脑后导入即可继续。
移动文件夹、换浏览器，或端口冲突而使用了新地址，都可能使原本的浏览器存储不可见。
方案 JSON 是跨电脑迁移的正式入口；转发程序 ZIP 不会自动附带你的私人方案。

排版与引用导出
“审阅与导出”可下载带样式的 Excel 工作簿，按指标、采集、方法参数、marker、证据和参考文献分表。
完整方案 HTML 包含封面、目录和 APA 7 引用；用浏览器打开后点击“打印／保存PDF”。
APA 引用格式和 Excel 导出库已包含在本地包中，导出本身不需要联网。
未知书目信息保留原始来源链接；网站不会编造软件版本、论文作者或实测指标。
纯数据 TSV、方案 JSON、Markdown 和思维导图导出继续保留。

分析起点与挂件
在研究范围中选择 FASTQ、带标签 BAM 或计数矩阵起点。已有矩阵可跳过读取处理和矩阵生成。
工具、指标和原始数据仍需由研究者核查；本工作站制定方案，不运行测序分析。
龙泡泡在资料页默认停靠顶栏；点击打开 AI 指引、设置与贡献入口，可拖动位置。首页保留游动效果。
默认素材来自在线图片源，需要联网；可在挂件设置中恢复、暂停、移动或隐藏。
离线时可在挂件设置中选用自己的本地图片；核心工作台与资料库仍可离线使用。

遇到问题
START 会在打开前检查发行包内文件的 SHA-256，发现缺失或损坏会指出具体文件。
请从原 ZIP 重新完整解压。不要把新版文件零散覆盖进旧版目录。
日志保存在 %LOCALAPPDATA%\YeastVar1011\portable\<目录标识>\server.log。
直接用 file:// 打开网页会受到浏览器的本地模块或数据读取限制，完整功能请用 START。
若单位策略禁止 PowerShell，使用在线版；本启动器不会改变系统安全策略。
