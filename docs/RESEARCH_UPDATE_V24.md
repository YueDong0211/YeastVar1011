# Research catalogue update v24

Updated 17 October 2026.

This update adds four research-plan routes, eight project audit metrics, two software entries and four verified method references. The source catalogue now contains 55 routes, 287 metrics, 155 tools and 213 literature records. These counts describe planning resources. Their analysis outputs are generated by the selected external methods and project analysis code.

## Added research routes

| Route | Question and outputs | Required input contract |
|---|---|---|
| `mechanistic_joint_rna_noise` | Compare transcription and sampling models using the joint mature/unspliced count distribution. Retain model fits, parameter uncertainty, boundary solutions and comparisons with mean changes. | Raw integer S/U layers on matched axes, an explicit count matrix for the default matrix/noise methods, reference-derived gene lengths, strain/culture metadata and comparable state strata. Independently recorded rate priors are optional. |
| `rna_measurement_length_audit` | Evaluate whether unspliced length dependence and measurement-model choices change kinetic parameters or noise candidates. | The same S/U layers, explicit count matrix, reference, metadata and state strata; record the length definition, count rules and common analyzed genes. |
| `cross_implementation_robustness` | Compare Seurat and Scanpy from a frozen matrix. Separate differences in representations and labels from differences in marker or noise inference. | The same original counts and ordered cell/feature identities, sample metadata and explicit algorithm/version settings. Fixed-label and reannotation branches are compared separately. |
| `noise_multiplicity_control` | Define the tested gene/state/contrast families and the error level attached to reported genes and individual claims. Use calibrated upstream tests for stage-wise screening and confirmation. | A named gene-screening p-value vector and a gene-by-contrast confirmation matrix in the same gene order, with estimands, inference units, eligibility and failure states. No additional DNA, bulk or phenotype assay is required. The calibration metric also requires simulation truth or independent truth. |

Monod is a conditional mechanistic comparison for the yeast project. Before fitting, assess the number and coverage of intron-bearing genes, the consistency of S/U counting, and parameter identifiability. GeneFull minus Gene is not an unspliced layer. Without independent time calibration, rates retain their model reference units. The catalogue links the official API and documents the biological model, sampling model, `use_lengths`, search bounds, grid settings and gene-selection decisions.

Both routes declare every input required by their default tools and state-conditioned metrics. The raw integer mature/spliced S layer may provide the separate count-matrix input after matching gene and cell identities and order to the S/U layers. Retain this counting definition throughout comparisons. S and U must not be mechanically added to create that input.

stageR is statistical post-processing of valid p-values. It does not estimate noise or correct invalid upstream tests. Its use for noise contrasts is an adaptation that needs justified screening/confirmation hypotheses and design-matched calibration. The template leaves the target OFDR and confirmation correction method as explicit choices. DTU-specific shortcuts and `method="none"` must not be transferred to unrelated hypotheses. Changing the target OFDR requires rerunning the complete stage-wise adjustment.

## Added metrics and implementation status

All eight entries use `metricOrigin: "project-audit"` and `collection.requiresImplementation: true`. Native function results remain separate from the proposed project export fields.

| Metric ID | Information retained |
|---|---|
| `monod_joint_fit` | Joint/marginal count fits, likelihood convention, model version and fit status. |
| `monod_parameter_support` | Parameter units, standard errors, search bounds and resampling support. |
| `unspliced_length_sensitivity` | Reference length definition, S/U moments and matched parameter/rank changes with length-aware sampling. |
| `sequencing_model_sensitivity` | Supported sampling models, search bounds, uncertainty and candidate stability. |
| `implementation_representation_concordance` | Frozen matrix/axis hashes, exact versions, HVG overlap, neighborhood overlap and clustering agreement. |
| `implementation_inference_stability` | Fixed-label versus reannotation results, marker direction/rank agreement, label coverage and original-count noise effects. |
| `noise_testing_family_registry` | Family and hypothesis IDs, estimands, eligible/assessed family sizes, raw p-values and failure states. |
| `noise_stagewise_error_calibration` | Screening/confirmation outputs, target OFDR, hypothesis logic, NA reasons and truth-based errors/power at the gene and individual-test levels. |

Missing, failed, unassessed and screening-not-passed results are distinct statuses. They are not converted into zero p-values or silently presented as assessed nonsignificance. Exploratory QC branches are retained for sensitivity analysis; their minimum p-values are not substituted into the primary hypothesis family.

## Coverage reviewed

The existing routes already address mean equivalence, mean matching, cell-number/depth power, culture-level resampling, tail-molecule evidence, state composition, missing-state support, annotation uncertainty and normalization targets. They also cover covariance, regulatory networks, trajectory/velocity feasibility, transcript processing and conditional genetic extensions. This update therefore adds specific missing decision logic rather than creating duplicate routes for those topics.

Marker discovery, functional annotation and literature candidates remain separate from observed state specificity in the study data. This update does not modify the marker shards or assign unmeasured expression values to genes.

## Offline citation corrections

The citation generator previously inferred preprint status from a `10.1101` DOI prefix. That prefix also identifies papers in Genome Research and Genes & Development. An audit of the 23 existing `10.1101` citation records identified four misclassified journal articles:

- UMI-tools: `10.1101/gr.209601.116`.
- dropkick: `10.1101/gr.271908.120`.
- Quiescence/transcription restart: `10.1101/gr.279874.124`.
- Hcm1/cell-cycle transcription: `10.1101/gad.1450606`.

Their CSL types are now `article-journal`; incorrect preprint/server attributes were removed. Authors, titles, years, volumes, issues, pages and DOIs were preserved. Nineteen preprint records retain their preprint descriptions, including the medRxiv source. The source generator now prioritizes publication metadata and never infers preprint status from a DOI registrant prefix.

The four new references are also included in the offline CSL catalogue. The length-bias paper retains its 2022 online date and 2023 citation/issue year. stageR is identified as a classical reference outside the recent-five-year literature window.

## Rebuild and validation

From the repository root:

```bash
node research/v24_research_additions.cjs
node research/qa-input-contracts-v22.cjs
node research/qa-csl-publication-types-v24.cjs
node research/check_site.cjs
```

The additions script is idempotent and uses the metadata already verified in its source. It updates the four catalogue JSON files, the v24 translation file and the four new offline CSL records, preserving retained citation corrections. It does not rebuild the offline catalogue bundle or marker shards. Once all catalogue and marker edits are complete, maintainers synchronize the offline bundle with:

```bash
python research/write_catalogue_assets.py
```

The v24 translation file supplies 126 text entries for Chinese, English, French, Spanish and Basque through the existing locale system. The website entry point must load that file before rendering the catalogue.
